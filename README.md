# 巴西电商销售与用户行为分析

基于 Olist 公开数据集（约 10 万订单），使用 Excel、SQL、Python 完成从数据清洗到业务洞察的完整分析项目。

## 技术栈
- Excel：数据清洗、数据透视表、VLOOKUP 多表关联
- SQL（SQLite）：多表 JOIN、窗口函数、子查询
- Python：Pandas 数据处理、Matplotlib 可视化

## 核心分析结论
- 总销售额：约 1600 万
- 复购率：3.1%（多数顾客仅购买一次）
- 晚到率：8.1%
- SP（圣保罗）州订单占比 42%，区域高度集中
- 信用卡支付占 74%

## 项目产出
- Excel 清洗后数据与 3 张透视表
- 15 条 SQL 查询脚本
- Python 分析脚本与 6 张可视化图表
